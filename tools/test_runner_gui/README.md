# Oxide Player Test Runner GUI

Графічний інтерфейс для запуску тестів Oxide Player.

## Запуск

```bash
cd tools/test_runner_gui
flutter pub get
flutter run -d windows
```

## Функціонал

- 📂 **Автоматичне виявлення** - Знаходить всі файли `*_test.dart`
- ▶️ **Запуск всіх тестів** - Одною кнопкою запускає всі тести
- 🎯 **Запуск окремого файлу** - Можна запустити тести тільки з одного файлу
- 📊 **Статистика** - Passed/Failed/Skipped в реальному часі
- 📋 **Деталі тестів** - Розгортка для перегляду окремих тест-кейсів
- 📝 **Вивід** - Повний лог виконання з можливістю копіювання

## Вимоги

- Flutter SDK 3.0+
- Windows 10/11
